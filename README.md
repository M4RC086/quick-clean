# 🧹QUICK-CLEAN🧹
Is your folder a mess? This tool organise your folder in a second with a single command. No GUI, no learning, no friction. Easy, right?

## USAGE
```bash
quickclean [folder]

#Example
quickclean ~/Downloads
```
The folder is optional. If it's empty, the actual folder will be cleaned

## ⚡INSTALLATION
```bash
# Linux bash
curl -fsSL https://raw.githubusercontent.com/M4RC086/quick-clean/main/setup.sh | bash
```
