# 🧹QUICK-CLEAN


Is your folder a mess? This tool organise your folder in a second with a single command. <b>No GUI, no learning, no friction</b>. Easy, right?

This is a <b>Linux</b> bash tool (no Windows). You only need to run a command. It's dead simple but that's the point


### PERFORMANCE
In my computer I tested with 1000 files and it took around 5 seconds to clean them (CPU: i7-3630QM).
Even if you have thousands of photos or something it should take some second. If you're a normal persone it will be instant
<br>
<br>

## INSTALLATION
Run this to install in /usr/bin/:
```bash
# In Linux shell
curl -fsSL https://raw.githubusercontent.com/M4RC086/quick-clean/main/setup.sh | bash
```
<br>
<br>


## HOW TO USE IT?
Once you already installed it:
```bash
quickclean [folder]
```
```bash
# The folder is optional. If it's empty, the actual folder will be cleaned
```
